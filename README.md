## This project is part of a bigger one. [This project](https://nasa-martian-map-6-3.vercel.app/)
## But here it's only the pars simulation 

### With this project you can:
- Walk on Mars.
- Follow a path made with the A* algorithm
- And discover 10 missions that have been made for real.

### Why ?
I made this in the contexte of the [NASA SPACE APP CHALLENGE](https://www.spaceappschallenge.org/) with my team [5/3](https://www.spaceappschallenge.org/2026/find-a-team/53/).

### Goal of this project
I used the real datas from the NASA to recreate the planet Mars. It has the same radius, and the real weather data.
It democratizes planetary science for students, educators, and the public by transforming raw NASA/USGS mission data into an intuitive, hands-on experience.

### Data used:
- [Mars Viking Colorized Global Mosaic 232m](https://astrogeology.usgs.gov/search/map/mars_viking_colorized_global_mosaic_232m)
- [Mars MGS MOLA DEM 463m](https://astrogeology.usgs.gov/search/map/mars_mgs_mola_dem_463m)
- [Mars Climate Database (MCD v6.2)](https://www-mars.lmd.jussieu.fr/)
